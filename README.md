# CSZ website (new design)

React 19 + Vite + Tailwind CSS v4 + React Router + lucide-react.

## Run it

    npm install
    npm run dev        # opens http://localhost:5173
    npm run build      # makes the dist/ folder to upload
    npm run assets     # optional: copies images from the old site (see the setup guide)

## Where things are

- `src/data/`        all the text: menu, events, people, members, history, Summit content
- `src/components/`  header, footer, hero helpers, marquee, counters
- `src/pages/`       one file per group of pages (Home, About, Membership, Summit...)
- `public/images/hero/`     the five hero photos
- `public/images/members/`  institutional member logos (18 of 36 included)

See the setup guide for the complete walkthrough.
